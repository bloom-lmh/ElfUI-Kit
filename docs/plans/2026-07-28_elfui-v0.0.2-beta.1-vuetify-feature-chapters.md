# ElfUI v0.0.2-beta.1 指南去重与能力收尾计划

日期：2026-07-28
状态：P0 已实现，P1/P2 保留为后续 API 计划

## 目标

参考 Vuetify 的跨组件能力，但不复制它的目录。ElfUI 每项能力只保留一个权威页面，避免 Features、Providers、Styles 与组件页互相重复。

## 最终信息架构

```text
Guide 指南
├─ Global configuration 全局配置
├─ Theme & customization 主题与个性化
├─ Icons 图标配置
├─ Internationalization 国际化
├─ Accessibility 无障碍
└─ Build & styles 构建与样式

Layout 布局
Basic 基础
Form 表单
Feedback 反馈
Data 数据展示
Navigation 导航
Picker 选择器
Utilities 工具类
```

## 唯一归属规则

- Blueprints、defaults、display、motion → Global configuration。
- Theme、palette、Sass/runtime token → Theme & customization。
- Icon fonts、sets、aliases → Icons。
- Locale、fallback、RTL → Internationalization。
- Application layout → Layout。
- Dates 与 date adapter → Picker。
- Programmatic scrolling → Anchor / BackTop。
- CSS utilities → Utilities。
- Entry points、reset、layers、tree-shaking → Build & styles。
- Keyboard、focus、ARIA、hotkeys、reduced-motion → Accessibility。

## 后续 API 计划

### P1

1. 抽取统一 `goTo` 服务，支持 container、offset、duration、easing 与 reduced-motion。
2. 定义 date adapter，允许原生 Date、Temporal、Day.js 或 date-fns 适配。
3. 增加 platform/SSR context 与 hydration 初始断点配置。
4. 为全局 component aliases 增加类型安全配置，而不是仅依赖局部 `useComponents`。
5. 设计单组件稳定入口后再承诺 tree-shaking 深层导入。

### P2

1. 外部 i18n adapter。
2. 可独立发布的品牌 preset 包。
3. token 文档与类型自动生成。
4. 无障碍 CI、浏览器矩阵与视觉回归。

## 验收标准

- 一级菜单不存在重复路由和重复能力名称。
- 每个 Guide 页面有明确用途、可运行案例、完整 script 和边界说明。
- 文档只展示当前 package exports 中真实存在的入口。
- 路由兼容不因菜单去重而中断。
- typecheck、测试、build 与截图检查全部通过。
