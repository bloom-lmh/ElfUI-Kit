# ElfUI v0.0.2-beta.1 信息架构、指令、质量与实验室实施计划

- 日期：2026-07-29
- Kit 版本：`0.0.2-beta.1`
- Framework 版本：`0.1.0-beta.20`
- 状态：实施中

## 1. 目标

在不复制既有 Guide、Provider、Utilities 和组件文档的前提下，建立四个职责清晰的一级目录：

1. **Getting started 快速入门**：让首次接入、升级和排障形成最短路径。
2. **Directives 指令**：为可附着到任意 DOM 元素的行为提供一致 API。
3. **Quality 质量**：集中维护可访问性、测试、性能和发布门禁。
4. **Labs 实验室**：隔离仍在验证契约的实验能力。

## 2. 信息架构

### Getting started

- Installation 安装
- Upgrade guide 升级指南
- Browser support 浏览器支持
- FAQ 常见问题

### Directives

本轮建立介绍与架构约束；子页面只有在实现、类型、测试、双语案例和浏览器验收完成后才加入菜单。

- 已有能力待统一：Draggable、Loading、Infinite Scroll
- P1：Click Outside（已完成）、Intersection Observer、Mutation Observer、Resize
- P2：Ripple、Scroll、Tooltip、Touch

每个指令与同名组合式能力共享唯一行为内核。指令负责 DOM 绑定，组合式函数负责状态复用，不允许复制监听、定位或清理逻辑。

### Quality

- Introduction 介绍
- Accessibility 无障碍
- Testing 测试
- Performance 性能
- SSR & Hydration 服务端渲染与水合
- Compatibility & Release 兼容性与发布

本轮迁移 Accessibility 的菜单归属，保留 `/guide/accessibility` 兼容路由。

### Labs

- Introduction 介绍
- Video 视频
- Heatmap 热力图

实验组件使用独立导出面，不进入 Kit 默认注册入口。其 API 允许调整，但必须有明确实验标识和迁移说明。

## 4. 完成标准

每个新增能力必须同时满足：

- 公开 API 与严格类型；
- 高内聚行为内核，指令/组合式/组件不复制实现；
- 卸载清理、SSR 安全、Shadow DOM 与 Teleport 边界验证；
- 中文、英文页面和可复制的 Template/Script；
- 单元测试、类型检查、生产构建；
- 真实浏览器交互、控制台零 warning/error 和截图；
- 计划、迁移说明、菜单和导出同步更新。

## 5. 非目标

- 不复制 Provider、Utilities、Accessibility 已有页面。
- 不以空白页面表示 Video、Heatmap 或尚未实现的指令。
- 不把实验组件加入默认稳定入口。
- 不为绕过框架缺陷而在组件层复制临时实现；确认框架问题后直接形成最小复现并反馈。
