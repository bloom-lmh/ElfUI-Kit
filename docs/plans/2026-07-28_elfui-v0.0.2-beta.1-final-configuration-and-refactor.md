# ElfUI v0.0.2-beta.1 全局配置与收尾重构计划

日期：2026-07-28  
状态：已完成

## 目标

在不改变现有组件行为的前提下，对齐 Vuetify 的配置思路，提供统一的应用级配置入口，并收敛 Provider、默认值合并、主题 token 与 overlay 层级实现。

## Vuetify 对标范围

- `createVuetify`：统一注入 defaults、theme、icons、locale、display 等子系统。
- `defaults`：全局默认值、组件默认值、嵌套覆盖与 reset。
- `theme`：命名主题、system theme、变量和主题切换。
- `icons`：默认图标集合、别名与多集合。
- `locale`：消息、fallback、RTL、数字格式化。
- `display`：断点、移动端判断、SSR 初始尺寸。
- `date`：可替换日期适配器。
- `goTo`：容器、偏移、持续时间与缓动。

## 本轮完成

- [x] 新增 `ConfigProvider`，组合 defaults、theme、locale、icons、display、motion。
- [x] 新增 `defineElfUIConfig()` 与 `mergeElfUIConfig()`。
