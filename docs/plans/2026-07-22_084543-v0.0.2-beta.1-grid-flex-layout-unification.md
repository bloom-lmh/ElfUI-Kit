# Grid / Flex / Layout 文档与能力统一计划

- 日期时间：2026-07-22 08:45:43（Asia/Shanghai）
- 组件库版本：0.0.2-beta.1
- 状态：已完成（库级 typecheck 受并行维护中的非本任务文件阻塞）
- 范围：Grid、Flex、Layout、Spacer 组件与对应文档案例

## 目标

1. 布局导航只保留 Grid、Flex、Layout 三个一级页面，不增加多级子页面。
2. Grid、Flex、Layout 使用同一套文档图示语言，去除互不相关的业务卡片和混杂边框风格。
3. Layout 保留所有不同的结构能力，合并相同骨架的产品化案例，并将本页目录平铺为一级锚点。
4. 补齐 Flex 容器级能力，新增轻量 Spacer，同时保持现有 Space 兼容 API 可用。
5. 新增生命周期代码统一使用 `onMounted`。

## 设计决策

### 页面边界

- Grid 页面承载 Container、Grid、GridItem 的组合说明与案例。
- Flex 页面承载 Flex、Spacer、Space 兼容属性及 Flex 子项工具类案例。
- Layout 页面只承载 Header、Aside、Main、Footer 的应用骨架组合。
- 侧边栏和页内目录均不创建多级分组。

### 统一案例视觉

- 采用简洁的结构图风格：实线边框、统一圆角、主题变量背景和固定间距。
- Grid 与 Flex 子项统一使用编号 1、2、3；Grid 可补充 span / offset 信息。
- Layout 使用固定语义色标识 Header、Aside、Main、Footer，并使用结构占位块而非业务卡片。
- 抽取布局文档共享样式，三个页面复用，支持亮色和暗色主题。

### Layout 去重后的平铺案例

1. 顶栏与内容：header + main
2. 侧栏与内容：aside + main
3. 经典后台：header + aside + main + footer
4. 双层顶栏：system bar + header + main
5. 嵌套双导航：rail + header + subnav + main + footer
6. 右侧详情栏：header + main + right aside
7. 三栏工作台：header + left aside + main + right aside
8. 多栏协作区：rail + secondary aside + main + right aside

以下重复结构合并：Baseline / Side navigation，Extended toolbar / header + main，Inbox / Store / 经典后台。Constrained content 移入 Grid 页面的 Container 说明。

## Flex 公共契约

### 新增与调整

- 新增 `alignContent`，支持 `stretch`、`flex-start`、`flex-end`、`center`、`space-between`、`space-around`、`space-evenly`。
- `wrap` 扩展为 `boolean | "nowrap" | "wrap" | "wrap-reverse"`。
- `wrap=true` 继续解释为 `wrap`，`wrap=false` 继续解释为 `nowrap`。
- 保留 `alignment`、`size`、`fill`、`fillRatio` 作为 Space 兼容输入，不扩大其职责。
- 响应式方向、对齐、顺序、grow/shrink、align-self 与自动 margin 继续由现有工具类承担。

### Spacer

- 新增 `<elf-spacer>`，无公共 props、事件或暴露方法。
- 默认插槽不参与结构；组件仅作为 `flex-grow: 1` 的语义化占位元素。
- 在 Layout 分类和组件库入口中完成注册与类型导出。
