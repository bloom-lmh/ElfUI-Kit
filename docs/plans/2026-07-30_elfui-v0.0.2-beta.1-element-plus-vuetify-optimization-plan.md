# 优化方案及其计划

## 顶层原则

采用“纯模型/状态机 -> 无 UI controller/adapter -> composable/provider -> component -> page”的依赖方向。高内聚意味着状态转换由明确所有者维护；低耦合意味着组件依赖小协议而不是彼此内部 DOM。优先使用组合、策略、适配器、状态机和受控/非受控协调器，不建立深继承组件体系。
