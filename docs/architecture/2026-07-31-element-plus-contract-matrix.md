# Element Plus Public Contract Matrix

- Authority version: `element-plus@2.14.3`
- Official documentation: [Element Plus components](https://element-plus.org/en-US/component/overview.html)
- Published contract source: [element-plus@2.14.3](https://unpkg.com/element-plus@2.14.3/)
- Kit version: `@elfui/kit@0.0.2-beta.1`
- Core version: `@elfui/core@0.1.0-beta.20`
- Scope: the high-risk component families owned by `EP-02` through `EP-10` plus
  their shared Form boundary. This matrix does not claim visual or behavioral
  acceptance for those follow-up packages.

The published Element Plus package and official documentation are the authority for
the Vue contract. Current Kit `defineProps`, `defineEmits`, public types, tests, and
expose methods are the authority for the Custom Element contract. Historical
component plans are evidence only.

## Status Vocabulary

| Status           | Meaning                                                                                               |
| ---------------- | ----------------------------------------------------------------------------------------------------- |
| `supported`      | Public names, defaults, payloads, and interaction semantics align without a recorded follow-up gap.   |
| `equivalent`     | The Kit provides a valid Custom Element equivalent; Vue-only installation or slot details may differ. |
| `missing`        | A required public payload, scoped binding, form behavior, keyboard path, or ARIA contract is absent.  |
| `not applicable` | The Element Plus contract is Vue-specific and has no useful Custom Element API equivalent.            |

## Cross-Cutting Decisions

- Vue `v-model` becomes `modelValue` plus `update:modelValue`; a compatibility input
  is normalized at the public boundary, and one internal model owns transitions.
- Controlled inputs always win over default inputs. Default state is initialization,
  not a second source that may overwrite later controlled updates.
- Form inheritance uses `useDisabled()`, `useSize()`, `useFormControl()`, and FormItem
  context. Components must not create local validation registries.
- Vue component instances and scoped slots are not copied mechanically. Custom Element
  methods, named slots, typed render callbacks, and composed child components are used
  only when the current Core/compiler contract supports them.
- Public payload differences are `missing`, not equivalent. Cascader `change` remains
  open until `EP-06` preserves compatibility while supplying the Element Plus value
  payload at the documented boundary.
- This matrix does not close `EP-02` through `EP-10`; those packages still own pure
  models, cleanup, performance, browser interaction, ARIA, and screenshot evidence.
