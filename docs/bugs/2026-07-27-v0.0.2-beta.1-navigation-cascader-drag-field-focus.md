# Navigation / Cascader / Drag / Field focus regression plan

- Date: 2026-07-27
- Version: v0.0.2-beta.1

## Scope

- Dropdown compositional items and Cascader options must return focus before a persistent overlay becomes `aria-hidden` / `inert`.
- Cascader's searchable-path example must own a real runtime `onSearchUpdate` handler.
- Input prefix icons must align with an idle label and follow the editable row only after the label floats.
- Tree drag interaction must reuse a public directive instead of maintaining an isolated drag contract.
- Horizontal Anchor controls must select the previous or next enabled anchor and navigate its content target.
- DatePicker and ColorPicker must share Input's filled underline, outlined notch, floating label and focus transition.
