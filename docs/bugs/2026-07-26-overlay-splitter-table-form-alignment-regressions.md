# 2026-07-26 · v0.0.2-beta.1 Overlay、数据与表单回归修复

## 目标

修复组件升级后的焦点隐藏、拖拽边界、虚拟表格刷新、浮层定位和表单案例对齐问题；所有交互问题补充自动化测试，并通过真实浏览器截图验证。

## P0 · 行为与可访问性

- [x] Cascader / Dropdown 关闭浮层前迁移焦点，禁止隐藏仍包含焦点的面板。
- [x] Splitter 不可调整 Panel 的相邻分隔线不可拖动，键盘调整同样受限。
- [x] Table 溢出提示跟随锚点滚动；虚拟大数据排序后立即刷新可见行。
- [x] Tree 虚拟树与拖拽案例重构为真实层级树，并提供可操作拖拽。
- [x] Anchor 水平滚动案例的左右控制可用。
- [x] Tabs 增加可拖动排序标签案例和对应交互测试。

## P1 · 布局与视觉

- [x] Scrollbar 命令控制标题状态使用稳定宽度，按钮不随数值跳动。
- [x] Input 前置图标与光标间距在全部外观中一致；状态案例统一基线。
- [x] Badge 动态值、零值与 RTL 案例保持徽标和承载卡片的视觉归属。
- [x] InputTag 多行标签与上边线保留舒适间距。
- [x] Select 三组复杂案例统一水平布局和控件基线。
- [x] ColorPicker 标签、输入内容与清除按钮不重叠。
- [x] DatePicker 标签、输入内容与清除按钮不重叠；月份与头部案例缩短垂直距离。
